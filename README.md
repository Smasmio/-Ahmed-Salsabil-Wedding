# دعوة فرح أحمد وسلسبيل

صفحة دعوة عربية متجاوبة، مبنية بـ HTML/CSS/JavaScript بدون إطار عمل أو خطوات بناء.

## الملفات
- `index.html`: الصفحة كاملة.
- `music.mp3` (اختياري): أضف ملف موسيقى تملك حق استخدامه بهذا الاسم لتفعيل زر الموسيقى.

## تشغيل محلي
افتح `index.html` في المتصفح. لا تحتاج إلى تثبيت برامج.

## النشر المجاني على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub باسم `ahmed-salsabeel-wedding`.
2. ارفع `index.html` (و`music.mp3` إن أضفته) إلى جذر المستودع.
3. افتح **Settings → Pages**.
4. تحت **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/(root)` ثم **Save**.
6. انتظر اكتمال النشر وافتح الرابط الذي سيظهر في صفحة Pages.

## قبل النشر
- راجع أن رابط الخريطة يشير إلى مسجد التقوى المقصود.
- توقيت العدّ التنازلي وإضافة التقويم مضبوط تقريبًا على الساعة 4:00 مساءً بتوقيت مصر؛ عبارة الدعوة تظل «بعد صلاة العصر». عدّل الوقت في JavaScript إذا أردت ساعة محددة.
- لم يُضف مكان احتفال إضافي لعدم تزويدنا بعنوانه.
- صفحة GitHub Pages عامة ويمكن لأي شخص لديه الرابط فتحها.
